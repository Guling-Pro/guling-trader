**本仓——三条可修（复核逐字对上代码，均无条件修，不依赖审判器结果）**：
1. **超时线程脱缰**：`dispatcher.py:316` wait_for 包 to_thread，超时后线程仍发全局按键而
   `finally`（:360）已放 win_lock。修法=代次标记（线程写回前校验未被作废）或超时后锁内复位
   窗口态再放行。⚠️ 范围：代次校验必须覆盖 `dialog_cleanup`（dispatcher.py:272-277）与

2. **抓表零请求-响应校验**：翻页键为全局按键，未落到 xiadan 时 grid 仍是上一张表；三个 grid
   查询非空即 succeed。修法=返回前按方法校验特征表头，不匹配即重抓或显式 failed——
   **「succeed 携错表出门」是结构缺陷不是概率问题，安静交易日证明不了它不存在，故不列入
   审判器依赖、直接修**。orders_active 走此路径且错表被消费侧读成「无挂单」，最险。
3. **重连后旧 reply 错投**（自网关名下升格为本仓项）：`ws_client.py:355` 发送用 `self.ws`

   `self.ws is ws` 比对，不一致丢弃并记日志。跨会话回执归属不依赖网关 id 策略兜底。
